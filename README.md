# ANYTHINGLLM-TO-DISCORD-BOT
### Explanation:
This project uses mainly python to create a connect a local AI application (AnythingLLM) to Discord. 
- **Up-To-Date:** Uses AnythingLLM version v1.18.0 and Python 3.8.

## Quick Start
1. **Unpack the Files**

Download and copy text from all of the files.

2. **Insert data into .ENV file**

Insert discord token, AnythingLLM API key, AnythingLLM URL and AnythingLLM workspace in the [.env file](keys.env) fie.

3. **Experiment / Feedback**

After running the script, you can experiment with the code or report issues / ideas in the [issues section](https://github.com/CoderBryan2012/ANYTHINGLLM-TO-DISCORD-BOT/issues).
### Prerequisites
- Discord App
- AnythingLLM
- Code Editor (maybe)
- Python - Discord Library
